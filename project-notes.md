# Заметки по проекту (Project Notes)

> Этот документ нужен для записи заметок по проекту, фиксации его статуса и этапов работы.

## Этапы

[x] Зафиксировать индивидуальную проектную тему 
[x] Создать публичный репозиторий на GitHub с понятным названием проекта.
[x] Добавить стартовые файлы: README.md, project-notes.md, api-plan.md.
[] Делать изменения маленькими шагами и собрать минимум 6 осмысленных коммитов.
[] Создать минимум 3 ветки для разных изменений.
[] Выполнить минимум 1 merge в main.
[] Специально изменить одну и ту же строку в двух ветках, чтобы получить конфликт.
[] Исправить конфликт вручную и сделать отдельный commit с исправлением.
[] Открыть GitHub Network и проверить, что граф веток виден.
[] В README.md или git-conflict.md кратко описать, где был конфликт и как он исправлен.
